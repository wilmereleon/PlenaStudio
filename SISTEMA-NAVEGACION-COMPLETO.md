- **Archivo:** `Navbar.tsx`
- **Características:** Scroll detection, backdrop blur
- **Responsive:** Menú horizontal desktop, hamburguesa móvil
- **Elementos:** Logo, navegación, búsqueda, carrito
- **Indicadores:** Puntos dorados para página activa
- **Animaciones:** Reducción de tamaño en scroll

- **Archivo:** `typography.css`
- **Fuentes:** 3 familias tipográficas premium

- **Variables:** 15+ tamaños responsive con clamp()
- **Estilos:** Clases para diferentes jerarquías
