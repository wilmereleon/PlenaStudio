🔍 Galería Premium con Lupa - Plena Studio

🎯 Funcionalidad Implementada

Se ha integrado un sistema de zoom premium para las imágenes del catálogo de joyería. La funcionalidad incluye:

🖱️ Zoom al Hover

Las imágenes se amplían automáticamente al pasar el cursor, permitiendo ver los detalles de las joyas con claridad.

✅ Implementado

🔍 Lupa Interactiva

El cursor se transforma en una lupa y la imagen sigue el movimiento del mouse para explorar diferentes áreas.

✅ Implementado

📱 Responsive

El sistema de zoom se adapta a diferentes tamaños de pantalla, optimizando la experiencia en móviles y tablets.

✅ Implementado

⚡ Performance

Animaciones suaves con CSS transforms para mantener 60fps y una experiencia fluida.

✅ Optimizado

🛠️ Especificaciones Técnicas

  • Componente: ImageWithZoom.tsx (React TypeScript)
  • Zoom Level: 2.5x (configurable)
  • Imágenes: 22 productos reales desde /public/InsumosIMG/
  • Animaciones: CSS transitions y transforms
  • Indicadores: Hover feedback y estado visual
  • Accesibilidad: Alt text y cursor states
